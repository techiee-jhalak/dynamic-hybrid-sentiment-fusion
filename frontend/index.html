Technical Details & Architecture
  • Dataset & Architecture: SemEval-2020 Task 9 (SentiMix Hinglish) 3-Class Dynamic Hybrid Fusion
  • Components: VADER Lexicon 3-Class Adapter + DistilBERT Sequence Classifier (Fine-Tuned)
  • Noise Quantification Module (NQM): N = 0.25·E + 0.25·R + 0.30·C + 0.20·S
  • Adaptive Router: If N ≤ 0.20, α = 0.02. Else α = clamp(σ(z), 0.02, 0.25) where z = 0.05·(20 - L) + 12.0·N
  • 3-Class Vector Fusion: P_final = α·P_VADER + (1-α)·P_DistilBERT; prediction = argmax(P_final)
