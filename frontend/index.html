DistilBERT Backbone

Fine-tuned distilbert-base-multilingual-cased on SemEval-2020 Task 9 train partition (14,000 code-mixed utterances). PyTorch CPU runtime.

VADER Adapter

Rule-based lexical sentiment engine mapped from [-1, 1] compound score into a normalized 3-class probability distribution vector via softmax temperature scaling.

Noise Metric (NQM)

Multidimensional surface: N = 0.25·E + 0.25·R + 0.30·C + 0.20·S assessing Emoji density, Character repetition, Script code-mixing, and Symbol noise.

Dynamic Router

Sigmoid router: α = σ(w_N·N + w_L·L + b) clamped to [0.02, 0.25]. When N ≤ 0.20, router defaults to α = 0.02 preserving transformer fidelity.
